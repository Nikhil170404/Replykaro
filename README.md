# ReplyKaro

Instagram & Facebook comment-to-DM automation. Someone comments a keyword on your post, ReplyKaro sends them a DM automatically.

Website: https://www.replykaro.com

## What it does
- Comment-to-DM and story-reply automation for Instagram and Facebook
- Visual flow builder: follow-gate, lead capture, delays, AI replies
- Subscriber lists with CSV export, and broadcasts
- Built on Meta's official API, with hourly send limits and an account-health page
